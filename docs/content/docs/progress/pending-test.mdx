# 待测试

- 视频创作台精简：根地址和旧地址均进入视频创作台，顶部不再显示其他功能入口。
- 设置保留：配置弹窗可以保存渠道、视频模型、视频参数、主题和 WebDAV 设置。
- 视频生成：文本提示词、参考素材、任务轮询、历史记录、预览和下载流程正常。
- Docker 部署：通过 nginx 提供静态前端，刷新 `/video` 及其他旧地址时能够回退到视频创作台。
- 首页：黑色背景、中上方动态描边文字和中下方视频创作台入口在桌面与移动端均正常显示。
- 首页背景：接入 LiquidEther WebGL 流体背景，黑色底层保留，桌面与移动端均应渲染非空画布；移动鼠标或触摸时背景产生流体响应，停止操作后自动演示恢复。
- 首页标题：`Video generation` 字号较上一版本增大约 30%；鼠标经过标题或按下标题时重新播放描边动画，开启减少动态效果时保持静态可读。
- LiquidEther 参数记录已由新的 GradientWaves 背景说明取代。
- 首页背景已重构为 GradientWaves：WebGL2 渲染紫粉色波浪、支持鼠标视差与低强度颗粒，黑色底层、标题和视频创作台入口应在桌面及移动端保持可读。
- 视频创作台：已移除提示词输入区的“查看提示词库”入口和选择弹窗；手动输入提示词及“查看我的素材”入口保持可用。
- 视频创作台：新增“我的素材库”入口。视频生成成功后自动保存至浏览器本地素材库，素材库以视频预览卡展示生成结果，可点击将其作为视频参考素材插入。
- 我的素材页：接入蓝白色 DotField 动态点阵背景，点阵尺寸为原设定的 150%，鼠标经过时点阵产生更明显的局部鼓起和光晕；背景层不占据内容布局且不拦截素材列表、筛选和弹窗交互。
- Docker 路由：修复 `/assets` 与 Vite 静态资源目录重名导致的 403，直接访问素材页时应正确回退到 SPA 入口。
- 页面交互：视频创作台和我的素材顶部新增返回首页入口；首页入口保留 SpecularButton 动态镜面高光，视频和素材页移除所有按钮动态扫光，仅保留鼠标悬停的边框与亮度高亮；视频创作台的生成记录框、视频要求框、清晰度/尺寸/秒数选项和素材页的搜索、筛选、素材卡统一为静态镜面材质。
- 视频页深色主题：视频创作台改用浅黑色中性配色，面板、输入框、选项和主按钮去除蓝色渐变，仅保留灰黑层次与悬停高亮。
- 首页背景：GradientWaves 参数按指定配置更新，地平线色为 `#5227FF`、波浪色为 `#FF9FFC`、波峰色为 `#FFFFFF`，并保持鼠标交互、视差、颗粒和完整透明度。
