# 功能介绍

## 视频创作台

- 输入文本提示词生成视频。
- 上传图片、视频或音频作为参考素材；Seedance 模型支持按素材编号理解提示词引用。
- 支持选择视频模型、比例、清晰度、时长、生成声音和水印。
- 支持查看生成进度、失败原因、历史记录、视频预览和下载。
- 生成结果和参考素材默认持久化到浏览器本地。

## 配置与用户偏好

- 支持配置多个 OpenAI 兼容渠道、API 调用格式、Base URL、API Key 和模型列表。
- 支持设置默认模型与各类生成偏好；视频创作台使用其中的视频模型和视频参数。
- 支持在设置中测试并配置 WebDAV，同步浏览器本地数据。
- 支持浅色和深色主题。

## API 与兼容性

AI 请求由浏览器直接发送到配置的接口，不经过本项目的服务端代理。视频生成支持 OpenAI 风格视频接口，以及火山方舟 Agent Plan / Seedance 接口。

## 当前限制

- API Key 存储在浏览器本地，只适合个人或可信环境。
- 本地参考素材能否被上游接口接收取决于接口兼容性；Seedance 的视频、音频参考素材建议使用公网可访问的 URL。
- 远程视频无法下载到本地 Blob 时，会保留原始 URL，后续可播放性取决于上游 URL 的有效期。
