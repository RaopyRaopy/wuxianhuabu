# Render 部署

[部署到 Render](https://render.com/deploy?repo=https://github.com/basketikun/infinite-canvas)

## 部署步骤

1. 点击部署链接。
2. 登录 Render 并按页面提示连接 GitHub。
3. 确认部署，完成后访问 Render 分配的 `.onrender.com` 域名。

## 数据说明

视频生成记录、参考素材和 API Key 默认保存在浏览器本地。Render 只负责托管静态前端；需要跨设备同步数据时，请在设置中配置 WebDAV。
